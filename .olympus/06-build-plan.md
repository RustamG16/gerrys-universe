Dependencies user explicitly requested. HTML accessible business buttons mirror universe, no pointer-only task. Independent static fallback uses CSS orbit lines/shapes where unsupported. Native video controls preload none. ResizeObserver and cap DPR 1.5, pause offscreen, visibility and reduced motion. Local storage safe try/catch for locale/scope. Avoid animation and entrance hiding content. Security no personal data or creds included.
